## New

- **Choose where links from other apps open.** A link from Discord, Slack or Mail can open in Little Arcadia or as a new tab in your window: pick one in Settings › General › "Open links from other apps in", or from the File menu, even while you're in Little Arcadia. Either way it opens in your default profile, as Settings › Profiles promised.

## Fixed

- **Token fields no longer crash the browser.** Clicking into a token field in Settings › Live Folders (GitHub, Notion, Bitbucket, Confluence) quit Arcadia on the spot. It now takes your token, shows it as bullets, and keeps Writing Tools out of it.
- **GitHub live folders load for accounts with lots of pull requests.** With many open or requested PRs, the folder never loaded and said it was having trouble connecting to GitHub. It now loads, and one PR GitHub won't show you no longer stops the folder from updating.
- **A link opened in a new tab brings its window forward,** and when no window is open you get one window with just that tab, not an empty tab beside it.
