## Fixed

- **Opening windows and moving tabs no longer logs a failed page load.** Right after a new window opened, or a tab moved to another window or profile, the app could ask the tab to load before it was ready. The page still loaded, but the failed request was left unhandled. Calls now wait for the tab, and a tab that has already closed is left alone.

## Smaller

- The mini player has Dia's rounded corners, a thin light rim, and a shadow that follows the curve.
- If you share crash reports and usage stats, an error report now names the app function that failed and its error code, and still nothing about your pages.
