date: 2026-09-29
headline: Private windows now leave nothing behind, as promised.
---

## Fixed

- **Switching theme and appearance no longer crashes Arcadia.** Changing the profile colour and then light or dark mode could quit the app while it was reading your extensions.
- **Screen sharing shares only what you picked.** A page could ask for your whole screen after you picked one window or tab, and another tab could use your approval. Now only the window or tab you picked can be shared, once, and only by the page you picked it for. Pages can no longer skip the picker to ask for the screen.
- **Downloaded apps get checked by macOS.** Downloads were missing the "downloaded from the internet" mark, so Gatekeeper didn't check apps you downloaded before they opened, including with Open When Done. Every download is marked now.
- **Private windows leave nothing behind.** Tidying up tabs in a private window saved them to disk, where they could reopen as regular tabs, and muting a site in a private window saved and synced the site's name. Both now last only as long as the private window. Links from private downloads no longer reach the downloads file either.
- **Deleting your first profile deletes its data.** Deleting "Personal" (with another profile left) removed it from the sidebar but kept its history, cookies, passwords, addresses, cards and site settings on disk. They're cleared now. Its extensions are turned off rather than removed, as the delete dialog says.
- **Removing a disabled extension keeps it disabled.** Arcadia turned a disabled extension back on for a moment in order to remove it. It's removed without ever running now.
- **Downloads in two profiles no longer get mixed up.** Pausing, cancelling or "Open When Done" on one profile's download could act on another profile's download.
- **Sync keeps deletions deleted.** Putting back an old backup of the sync folder could bring back passwords or bookmarks you'd deleted, and a crash at the wrong moment could stop some changes from reaching your other Macs.

## Smaller

- In a private window, only extensions that are allowed in private windows and can run privately show a button. Others still work on pages.
- Removing an extension no longer deletes any folder; extensions you loaded from a folder stay where they were.
- A web page can no longer crash Arcadia by sending it malformed messages, or answer in place of the app's own page checks.
- An extension with broken translations shows an error instead of crashing when you load it.
- Turning off "Share anonymous crash reports and usage stats" also stops an upload that's already underway.
