# Speed, 0.2.24 → 0.2.25

The 0.2.25 release gate, 2026-10-04: the 0.2.24 export against the 0.2.25 export (built from 806eb3c7, the tagged
commit), one Apple Silicon Mac, hidden instances, both apps interleaved run by run in one `native-bench.mjs` process
(docs/perf/README.md). Medians, with min–max and the number of runs. Both apps share NATIVE_API_VERSION 6 and ran
0.2.25's bench bundle, so only native code differs.

In the full round, tab switch (32 → 37 ms) and renderer wakeups with one tab (1.9 → 2.1 /s) separated with n=2; a
second interleaved round of the session's switch and idle parts with 4 runs (second table) overlaps on every row
(34 → 32 ms, 2.0 → 1.9 /s). The release passed: the same or better everywhere.
