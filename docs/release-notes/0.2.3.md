## New

- **Translate pages, on your Mac.** When a page isn't in your language, a translate button appears; choose "Translate to…" or another language, or "Never Translate This Site". It uses macOS's own translation models, so nothing leaves the Mac, keeps links and styling, translates what you're reading first and the rest as you scroll, and Show Original puts the page back exactly. Needs macOS 26.
- **Delete a tab group.** Delete Group removes a group; it waits under Recently Deleted Groups for a week in case you want it back. Closing a group still keeps it under Recently Closed.
- **Suggest strong password.** Sign-up forms offer a strong generated password, saved to Netnyahoo's own password store.

## Fixed

- **Focusing a credit-card field no longer crashes Netnyahoo.** With a saved card, focusing a card-number field on a secure page quit the app; the card suggestions now show and fill.
- **"Allow ads on this site" works in every profile.** The site menu's ad-blocking switch only reached the first profile, and could stop working after a while until you restarted. It now takes effect on the next reload, in every profile, both ways.

## Smaller

- Every Developer Tools window is titled "Developer Tools" with the page's address, like Dia.
