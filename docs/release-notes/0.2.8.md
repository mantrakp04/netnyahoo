## Fixed

- **Quitting no longer crashes.** In 0.2.6 and 0.2.7, every quit ended in a crash report, and so did every update, since updating quits the app. Netnyahoo now closes its windows before shutting the engine down and exits cleanly.
- **Every shortcut works wherever the focus is.** ⌘1–⌘9 did nothing unless a web page had the focus: with the sidebar, the command bar or developer tools focused, the key was swallowed. They now pick the sidebar's rows in order: pinned tiles, pinned groups, then your tabs. ⇧⌘C copies the URL again instead of starting the element picker.
- **Switching profiles is smooth.** Swiping between profiles flashed an empty grey window and the old page under the new sidebar, and swipes after the first did nothing for a few seconds. The next profile now slides in whole, and back-to-back swipes all register.
- **Pinned tabs stay when you close a window.** Closing a window took its pinned tabs with it, so the next window had none. As in Dia, they belong to the profile: the profile's next window gets them back, in order. With sync on, they no longer disappear from your other Macs either.
- **Holding ⌘W ends by closing the window.** With a pinned tab open, ⌘W alternated forever between a New Tab page and the pinned site, reloading it every time. Now ⌘W shows another pinned tab that's still loaded, and closing the last tab closes the window, as in Dia.
- **Typing in the address bar keeps up.** Suggestions lagged behind each key, and fast typing stuttered. Each keystroke now updates the suggestions right away.

## New

- **Chrome's shortcuts, alongside Dia's.** ⌘E uses the selection for Find, ⌘O opens a file, ⌘. stops loading, ⇧⌘D bookmarks all tabs, ⇧⌘I emails the page's link and ⌥⌘P prints with the system dialog. Chrome's alternates work too, like ⌘← and ⌘→ for back and forward, ⌥⌘→ and ⌥⌘← for the next and previous tab, and ⌃⌘F for full screen. Where Chrome and Dia disagree, Dia's key wins.
- **Big Yahu on the New Tab page.** He replaces Dia's mark above the New Tab bar, rising from behind it when the page opens. The sidebar's New Tab row shows his head.
- **Liquid Glass tiles and address field.** On macOS 26, pinned tiles and the address field are Liquid Glass, tinted by your theme and profile colour. The selected tile is raised, brighter glass instead of a thick ring. The Liquid Glass sidebar style from 0.2.6 is gone, and the sidebar is Dia's again.
- **Optional crash reports.** Settings › Privacy & Security › "Share anonymous crash reports and usage stats" is off unless you turn it on. It never sends the sites you visit, page titles or anything you type; "What's Sent" lists every field. You'll be asked once, on the New Tab page.

## Smaller

- The space under the sidebar's address field matches the space between the pinned tiles and your tabs.
- The New Tab row's icon follows a switch between light and dark mode.
- File › Save Page As… saves the current page.
