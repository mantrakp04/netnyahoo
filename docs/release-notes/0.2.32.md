## Fixed

- **Netnyahoo no longer waits on a check for managed Macs when it opens.** Since 0.2.31, every launch asked macOS whether an organization manages the Mac before showing the window, which held up startup by about 10–20 ms. Netnyahoo doesn't read those settings, so it no longer asks.
