Netnyahoo's windows are rebuilt. Until now, each window you saw had an invisible Chrome window behind it that really owned your tabs, and everything Chrome draws for itself (menus, dialogs, popups, prompts) belonged to that hidden window. Now every window is Chrome's own, with Netnyahoo's sidebar and toolbar inside it, so Chrome's menus and dialogs show up where they should without special fixes.

## New

- **Every profile has its own window underneath.** Swiping between profiles, or ⌃1–9, moves the whole window to that profile's own Chrome window, so passkeys, autofill and right-click work the same in every profile.
- **The profile's name sits next to the window buttons, like Dia.** With two or more profiles, the sidebar header shows the profile's name in its colour; click it to switch profiles, create one, or open Settings › Profiles.
- **Send Feedback opens a GitHub issue.** Help › Send Feedback starts a new issue with your version and macOS details filled in.

## Fixed

- **Pages get your languages.** Pages were always told you read US English. They now get your macOS language order, so sites answer in your language, and the ad blocker turns on your region's list.
- **The release notes stay in front after an update.** A restored session's tab could take over the release-notes tab as soon as it opened (0.1.6 too).
- **Sized popups and full-screen profile paging behave.** Popups that open at a set size are proper windows of their own, and switching profiles in full screen shows the other profile's pages.

## Smaller

- The address bar shows a website's host alone, without "www." or the page title, like Dia 1.50; View › Show Full URL adds the path.
- Sidebar rows and pinned tiles use Dia 1.50's sizes, spacing and hairline outlines, and selecting a row no longer nudges it sideways.
- New Tab rows show the Dia-style mark with its concave bottom.
- The Downloads button appears only while the window has downloads listed.
- The tab clean-up card's buttons fit at any sidebar width, and are named Clean Up Once, Clean Up Daily and Not Now.
- The View menu is grouped like Dia's, and Force Refresh appears while ⇧ is held.
- The window buttons sit where Dia's do.
