## Fixed

- **Drag the window by its tab strip.** With tabs on top, only the strip's top edge moved the window; most of it ignored you. Now any empty part of the strip moves it, in both layouts, and dragging it to a screen edge tiles it as in any Mac app.
- **Double-click the tab strip to fill or zoom.** It did nothing. It now does what System Settings › Desktop & Dock › "Double-click a window's title bar to" says: Fill, Zoom or Minimize.
- **Clicking inside the address bar puts the cursor there.** A click in its text closed the bar instead, in every layout and in Little Arcadia. Click, drag and double-click now place the cursor and select as you'd expect.
- **Profile swipes keep working with the pointer still.** After swiping to another profile and back, the next swipe did nothing until you moved the pointer.
- **Copy Image and Copy Link Address no longer quit Arcadia.**
- **"Sign in with" prompts no longer quit Arcadia.** A site's "Sign in with" prompt, the warning before an insecure http page, and the leaked-password warning now show over their page.
- **A site asking to reopen files you gave it no longer quits Arcadia.** It asks in the usual permission prompt.
- **Create QR Code is gone from a page's right-click menu,** where picking it quit Arcadia.

## Smaller

- Window › Zoom is back in the Window menu.
