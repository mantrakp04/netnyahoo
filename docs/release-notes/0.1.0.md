The first public build: a Mac browser modeled on Dia, running our own build of Chromium 154 (CEF 154.0.28, Chrome style) with the ungoogled-chromium patches and H.264/AAC playback. Apple Silicon, macOS 14 Sonoma or later.

## New

- Sidebar tabs, spaces and profiles.
- Split view.
- Chrome Web Store extensions, kept up to date automatically.
- uBlock Origin Lite, built in.
- Chrome's password manager and autofill.
- Passkeys from a security key or a phone.
- Import from other browsers.
- Automatic updates (Arcadia › Check for Updates…).

## Not yet

- No sync.
- No Translate.
- No Widevine DRM, so some streaming services won't play.
- iCloud Keychain passkeys wait on Apple granting the browser passkey entitlement.
