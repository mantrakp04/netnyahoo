## Fixed

- **Profile swipes respond as you move.** Dragging and reversing now run natively, including while the rest of the interface is busy. A new swipe takes over the current motion without waiting for the previous animation.
- **Links opened behind stay behind.** Background tabs follow the page that opened them, in the order you opened them. Closing a tab returns to a related tab, and links from groups and splits keep their place.
- **Extension pages keep their links and profile.** Links from extension popups and side panels honour new-window, private, split and background choices. Forms and pages opened by scripts keep their original contents.
- **Reopened windows keep Back and Forward.** Reopen Closed Window restores each tab's navigation history.
- **Searching selected text follows the keys you hold.** The page menu and selection popover honour ⌘ for a background tab, ⇧⌘ for a foreground tab, ⇧ for a new window and ⌥ for a split. Opening bookmarks and history from a private window keeps them private.

## Smaller

- Scrolled sidebar rows stay below the traffic lights and profile name.
- Tabs on top include collapsible tab groups.
- Updating tabs does less work, so the rest of the interface has more time to respond.
