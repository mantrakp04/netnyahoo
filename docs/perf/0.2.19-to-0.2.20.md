# Speed, 0.2.19 → 0.2.20

Where 0.2.20's release-note numbers come from: the dogfood agent's runs on 2026-10-01, one Apple Silicon Mac,
hidden instances. Medians, with min–max and the number of runs.

- Native: `apps/browser/scripts/perf/native-bench.mjs`, the 0.2.19 export against a Release build of main at
  b203f949. The commits between it and the 0.2.20 release commit (ce2e8850) weren't benchmarked.
- JS: the bench channel (`apps/browser/scripts/perf/bench-entry.js`, production bundles), 0.2.19's bundle against
  main's on the same native build. `open20`/`close20` are opening and closing 20 tabs; `otherJsMs` is the app's
  JS work outside React commits; `writeKB` is what the app wrote to disk.
