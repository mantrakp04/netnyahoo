# Speed, 0.2.22 → 0.2.23

The 0.2.23 release gate, 2026-10-03: the 0.2.22 export against the 0.2.23 export (d8cce891), one Apple Silicon Mac,
hidden instances, both apps interleaved run by run in one `native-bench.mjs` process (docs/perf/README.md). Medians,
with min–max and the number of runs. Both apps ran the same bench bundle (built from 0.2.23's tree; the control's copy
has NATIVE_API_VERSION 5), so only native code differs. The bundles are kept in `dist/<v>/bench/`.

The first candidate (0c73d606) put a new window on screen 16 ms later than 0.2.22 (53 ms against 37, reproduced in a
second round): 1c216d62 made a ⌘N window key before its content mounted. d8cce891 makes it key as it shows, and the
release was rebuilt from it. Memory and tab switch, which separated by a few MB and 2 ms in the final round, were
rerun on their own (second table): the same or better.
