# 0.2.26 → 0.2.27 release gate

`native-bench.mjs --only launch,session,windows,idle --launch-runs 6 --runs 2`, 0.2.27's export against
0.2.26's (control bundle `dist/0.2.26/bench/main.jsbundle`, native API 6 vs 8), interleaved. The display
went to sleep during 0.2.26's second session round and the watchdog stopped the run there, so 0.2.26 has
one session round and 0.2.27 two.

| Median | 0.2.26 | 0.2.27 |
|---|---|---|
| launch: window (n=6) | 800 ms | 769 ms |
| launch: first frame | 990 ms | 980 ms |
| launch: JS | 559 ms | 547 ms |
| tab switch | 37 ms | 28 / 28 ms |
| new tab | 132 ms | 110 / 102 ms |
| new window: first frame | 161 ms | 115 / 101 ms |
| new window: window | 61–63 ms | 34–40 ms (round 2) |
| idle, 1 tab | 0.13 %, 6.9 /s | 0.13 %, 6.8 /s · 0.16 %, 7.3 /s |
| idle, 20 tabs | 0.86 %, 28.5 /s | 0.87 %, 28.8 /s · 1.08 %, 26.7 /s |
| memory, 20 tabs | 1223 MB | 1200 / 1219 MB |

Same or better throughout. In 0.2.27's first session round (the owner at the keyboard: 33 s of input in
its idle windows) two new-window samples recorded no window time and one 1493 ms; its second round, with no
input, measured 32–40 ms. The new outside-press watcher is an app-local mouse-down monitor and costs
nothing at idle (1-tab idle wakeups equal).
