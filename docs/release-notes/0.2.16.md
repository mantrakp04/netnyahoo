## Fixed

- **The "extension added" popup can be closed.** After installing an extension from the Chrome Web Store, its confirmation sat in the middle of the window with no way to close it. It now appears in the top-right corner with a close button, and Esc or a click elsewhere closes it.

- **Arcadia is called Arcadia.** Chrome's own dialogs and settings pages said "Chromium" in places, such as "has been added to Chromium". They now say Arcadia; the credits still name the Chromium project.
